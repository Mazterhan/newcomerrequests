# Newcomers Access Portal

Standalone prototype for managing newcomer access. Open it through XAMPP at:

`http://localhost/newcomers/access-portal/`

The SQLite database is created automatically in `storage/portal.sqlite` on first launch. This folder is deliberately excluded from version control; delete the database to reset all prototype data.

The app does not read or modify `Primark.xlsx`, `Primark KT.one`, or any file in the `forsageprint` project.
